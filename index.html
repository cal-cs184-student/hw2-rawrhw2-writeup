Briefly explain de Casteljau’s algorithm and how you implemented it in order to evaluate Bezier curves. De Casteljau's algorithm is an algorithm used to parametrically define a curve given a number of points in space. Given a string of points, create a parameter that begins at 0 and goes to x. For each value of the parameter, create a point on each line between consecutive points which falls at the value/x fraction of the way along that line. You now have a set of points which is one fewer than the starting set of points. Repeat this recursively until you are left with one point only. That point is on the line, and is the point corresponding to the stated value of the parameter x. If this process is repeated for all values of the parameter from 0 through x, then the set of all the points on the curve will define a curve. I implemented it in mych that way, using a simple set of equations to create a function which took care of a single recursive step, iterating through each line segment in a loop until all points in the current set have had the intermediates calculated.

Part 2: Bezier surfaces with separable 1D de Casteljau

For a two dimensional surface, we can break it down into a bunch of one dimensional bezier curves. We do this by, along one axis, calculating the bezier curves. We then use points parametrically along those curves to calculate the bezier curves along the other axis. This additional stage results in an initial grid of points turning into a spaced set of curves, which then are used to calculate a continuous surface.

Section II: Triangle Meshes and Half-Edge Data Structure

Part 3: Area-weighted vertex normals

I implemented area weighted vertex normals by calculating the area of each triangle using a cross product of the two edges going away from the given vertex, and then adding the product of that area and the triangle's face normal to the current vertex normal. I repeated this procedure for each triangle surrounding the vertex, ending up with a normal vector for the vertex which was a weighted average of all the surrounding faces' normals. I then reduced this to a unit vector.

Part 4: Edge flip
